# Book-to-Skill Converter

Конвертирует книгу в Claude Code skill с субагентной архитектурой.

**Вход:** путь к файлу книги (PDF, EPUB, MD, TXT) — `$ARGUMENTS`

---

## Инструкция

Ты — генератор скилов из книг. Твоя задача: превратить книгу в готовый Claude Code skill, который использует субагентов для применения знаний из книги.

Работай строго по пайплайну ниже. Каждый этап — отдельный шаг с чёткими артефактами.

---

### Этап 1: Анализ структуры книги

Прочитай книгу по пути `$ARGUMENTS` используя Read tool (для PDF используй параметр pages, читай порциями по 15-20 страниц).

Составь структурную карту книги:
- Основная тема и домен знаний
- Ключевые разделы/главы и их суть (1-2 предложения на каждый)
- Практические методологии, фреймворки, алгоритмы
- Целевая аудитория и уровень экспертизы

Сохрани карту во временный файл `/tmp/book-analysis.md`.

---

### Этап 2: Извлечение компонентов знаний

Запусти параллельных субагентов (Agent tool, subagent_type: "general-purpose") для глубокого анализа каждого крупного раздела книги. Каждый субагент получает:

- Путь к файлу книги и диапазон страниц/разделов для анализа
- Задачу: извлечь из своего раздела:
  - Конкретные техники, методы, паттерны
  - Правила и принципы (do/don't)
  - Примеры применения
  - Связи с другими разделами

Промпт для каждого субагента:
```
Прочитай файл {путь_к_книге} (страницы/раздел: {диапазон}).
Извлеки и структурируй:
1. ТЕХНИКИ: конкретные методы и алгоритмы действий
2. ПРИНЦИПЫ: правила и ограничения (что делать / чего избегать)
3. ПАТТЕРНЫ: повторяющиеся шаблоны решений
4. ПРИМЕРЫ: конкретные кейсы применения
5. СВЯЗИ: как этот раздел связан с остальными темами книги

Результат запиши в /tmp/book-component-{N}.md в структурированном виде.
```

Количество субагентов = количество крупных разделов (обычно 3-7). Запускай их параллельно.

---

### Этап 3: Синтез ролей

После завершения всех субагентов из Этапа 2:

1. Прочитай все файлы `/tmp/book-component-*.md`
2. Проанализируй извлечённые знания и выдели **роли** — логически связанные группы компетенций, которые будут субагентами в финальном скиле

Для каждой роли определи:
- **Название роли** (короткое, понятное)
- **Зона ответственности** — какие задачи решает
- **Ключевые знания** — какие техники/принципы из книги использует
- **Входы/выходы** — что получает и что возвращает

Типичные паттерны ролей:
- **Аналитик** — оценивает ситуацию, ставит диагноз
- **Стратег** — выбирает подход, планирует
- **Исполнитель** — применяет конкретные техники
- **Ревьюер** — проверяет результат по критериям из книги

Сохрани описание ролей в `/tmp/book-roles.md`.

---

### Этап 4: Генерация препромптов

Запусти параллельных субагентов — по одному на каждую роль из Этапа 3. Каждый субагент генерирует **препромпт** для своей роли.

Промпт для каждого субагента:
```
Ты генерируешь системный промпт для AI-субагента с ролью "{название_роли}".

Контекст роли:
{описание_роли_из_этапа_3}

Исходные знания из книги:
{релевантные_компоненты_из_этапа_2}

Создай промпт, который:
1. Чётко определяет роль и экспертизу субагента
2. Содержит конкретные инструкции на основе знаний из книги (техники, принципы, паттерны)
3. Определяет формат входных данных и ожидаемого результата
4. Включает критерии качества и типичные ошибки
5. Написан как прямое обращение к субагенту ("Ты — ...", "Твоя задача — ...")

Промпт должен быть самодостаточным — субагент не имеет доступа к книге.
Запиши результат в /tmp/book-preprompt-{название_роли}.md
```

---

### Этап 5: Сборка финального скила

Прочитай все препромпты из `/tmp/book-preprompt-*.md` и собери финальный skill-файл.

Структура финального скила:

```markdown
# {Название скила на основе книги}

{Краткое описание: что делает скил, на основе какой книги}

**Вход:** $ARGUMENTS

---

## Инструкция

{Описание общей задачи и контекста}

### Шаг 1: Анализ задачи
{Инструкция для первичного анализа входных данных пользователя}

### Шаг 2-N: Запуск субагентов
Для каждой роли — блок с инструкцией запуска Agent tool:
- subagent_type: "general-purpose"
- prompt: {препромпт роли} + {данные от пользователя}
- Параллельно где возможно

### Финальный шаг: Синтез
{Инструкция по объединению результатов всех субагентов в финальный ответ}
```

Сохрани финальный скил в `.claude/commands/{название-скила}.md` в текущем репозитории.

---

### Этап 6: Отчёт

Выведи пользователю:
- Название сгенерированного скила
- Список ролей/субагентов с кратким описанием
- Путь к файлу скила
- Как использовать: `/{название-скила} <описание задачи>`

Удали временные файлы из `/tmp/book-*`.
